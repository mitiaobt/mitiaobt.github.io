# mitiaobt.github.io

Personal website of Mitia Oberti. It is plain HTML with no build step, so changes go live as soon as they are pushed.

- All the content is in `index.html`. Comments there explain how to add a paper.
- Colors and layout are in `assets/site.css`.
- To update the CV, replace `files/CV_MITIA_OBERTI.pdf`, keeping the same name.

## Folder layout

| Path | What it is |
| --- | --- |
| `index.html` | The website |
| `assets/` | Stylesheet and script |
| `images/` | Photo and tab icons |
| `files/` | The CV |
| `404.html` | Page shown for a wrong address |
| `about/`, `research/`, `teaching/`, `cv/` | Redirects, so links to the old pages still work |
| `google85f10b33c9daa5c1.html` | Google Search Console ownership check |
| `.nojekyll` | Tells GitHub Pages to publish the files as they are |

The previous Jekyll site is kept on the `old-site` branch and the `old-site-2026-11-06` tag.
